如何理解HTML语义化？

  1. 使标签具有语义，更具有可读性
  2. 可以帮助机器阅读，分析html代码，SEO优化

常见的块级标签？内联元素？

块级标签：div h1-h6 table ul ol p等

内联：span,img,input,button 等

CSS

盒模型宽度计算

offsetWidth = (内容宽度 + 内边距 + 边框*2) 无外边距

Border-box : 包括外边距

margin纵向重叠问题

  • 相邻元素的 margin-top 和 margin-bottom 会发生重叠

  • 空白内容的＜p>

    也会重叠

margin 负值问题

margin-top 和 margin-left 负值，元素向上、向左移动

margin-right 负值，右侧元素左移，自身不受影响

margin-bottom 负值，下方元素上移，自身不受影响

对BFC的理解与应用

BFC：块级格式化上下文

  • 一块独立渲染区域，内部元素的渲染不会影边界以外的元素

形成BFC的常见条件

  • float 不是 none
  • position 是 absolute 或 ffixed
  • overflow 不是 visible

实现一个圣杯布局(三栏布局)

  • 首先，将left和right设定固定的宽度
  • 将left center right 浮动
  • 给container设置一个等同于left，right宽度的padding
  • 给left加相对定位，right宽度，加margin-left：-100%
  • 给right加 margin-right: 宽度;

实现一个双飞翼布局（三栏布局）

  1. 设定三个盒子，其中center盒子需要再里面加一层main
  2. 给left和right设定一个宽度，给center宽度设为100%
  3. 给main加左右margin，大小同等于left，right的宽度
  4. 给left设置一个margin:-100%,给right设置一个margin：-宽度

CSS的定位问题

  • relative 相对于自身定位 不会脱离文档流
  • Absolute:相对于最近的带有定位的祖先标签，会脱离文档流
  • sticky：粘性定位可以被认为是相对定位和固定定位的混合。元素在跨越特定阈值前为相对定位，之后为固定定位。设置该属性的元素并不脱离文档流，仍然保留元素原本在文档流中的位置。
  • fixed：相对于窗口定位，会脱离文档流

居中的方式

水平居中
  1. inline元素：text-align:center
  2. block元素：margin:auto
  3. absolute元素：left:50% + margin-left负值
垂直居中
  1. inline元素：line-height = height
  2. absolute元素：transform(-50%)

Line-height如何继承？

  • 具体数值会继承具体数值
  • 比例也会继承比例
  • 但写百分比，会继承百分比算出来的数值

CSS的相应式

rem是什么？

rem是一个长度单位。

px是绝对长度单位，不会改变大小。

em是相对长度，相对于父元素。

rem是相对于根元素的长度单位，常用于相应式。

媒体查询：根据不同大小设置不同的css样式

vw和vh

rem的弊端：配合媒体查询使用的时候，会有阶梯性（离散的）。

vh和vw相对于网页可视窗口大小的百分比。
