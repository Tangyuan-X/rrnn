5 种常用布局的 flex 实现

5 种常用布局的 flex 实现

原文地址：https://juejin.cn/post/6844903517241491463

Sticky Footer

经典的上-中-下布局。

当页面内容高度小于可视区域高度时，footer 吸附在底部；当页面内容高度大于可视区域高度时，footer 被撑开排在 content 下方

解析：body使用flex纵向排列分成三块，中间部分添加flex auto使得宽度自适应为剩余宽度。

Fixed-Width Sidebar

在上-中-下布局的基础上，加了左侧定宽 sidebar。

解析：在上一个布局的基础上，content分解为asisde和content，aside定宽，content设为auto吸收剩余高度。

Sidebar

左边是定宽 sidebar，右边是上-中-下布局。

解析：body设为flex布局，将aside和container横向排列，老套路，contaner设为auto吸收多余宽度，contaner为纵向flex，container吸收高度。

Sticky Header

还是上-中-下布局，区别是 header 固定在顶部，不会随着页面滚动。

解析：在第一个布局的基础上，给header添加position: fixed; header脱离普通文档流，加left 和right都为0使得其宽度等于视窗大小，body添加padding-top顶下去content

Sticky Sidebar

左侧 sidebar 固定在左侧且与视窗同高，当内容超出视窗高度时，在 sidebar 内部出现滚动条。左右两侧滚动条互相独立。

解析：在slider布局的基础上，给body定高100vh，给aside添加overflow即可。
