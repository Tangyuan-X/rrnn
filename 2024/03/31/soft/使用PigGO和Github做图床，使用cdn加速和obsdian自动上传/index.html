使用PigGO和Github做图床，使用cdn加速和obsdian自动上传

使用PigGO和Github做图床，使用cdn加速和obsdian自动上传

下载picgo

下载地址 https://molunerfinn.com/PicGo/[PicGo](https://molunerfinn.com/PicGo/)

github创建仓库

新建一个仓库用于保存我们的图片。

获取githubToken

在上传图片时，需要核验我们的身份，我们需要新建一个密钥token。

Setting -> Developer Settings

一定要勾选repo权限。

请及时保存密钥，它只会出现一次。

配置picgo

我们打开Picgo

github国内不稳定，可以用cdn加速，地址为 https://cdn.jsdelivr.net/gh/用户名/仓库地址

配置好，可以上传试试，记得更改图床

成功后即可！，可以打开github仓库看看，可以打开picgo开机自启。

在obsdian设置自动上传

安装image-auto-upload插件，启用即可。
